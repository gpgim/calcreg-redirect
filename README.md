# Redirecionamento calcreg.com.br → cire.app.br

Este repositório só serve para levar quem acessa o endereço antigo **calcreg.com.br**
(citado no livro e no manual) para o site atual da CIRE em **https://cire.app.br**.

As páginas antigas (`/sobre`, `/equipe`, `/manual`, `/termos`) vão para as páginas
equivalentes. Qualquer outro endereço vai para a página inicial.
